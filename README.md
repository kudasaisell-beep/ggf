# 🤖 Shop Bot — Мульти-магазин аккаунтов

Полностью рабочий Telegram-бот для продажи аккаунтов с LZT.market.

## ✨ Возможности

- 🛒 **Покупка** — категории: Мессенджеры, Игры, Сервисы
- 💰 **Пополнение** — карта, QR СБП, Telegram Stars
- 🛡 **Гарантия** — 24ч стандарт / пожизненная со страховкой
- 🔒 **Безопасность** — фильтрация брут/фишинг/стиллер
- 📊 **Админ-панель** — статистика, управление ценами, тикеты
- 🎫 **Поддержка** — тикетная система
- ⭐ **Отзывы** — рейтинг и отзывы покупателей

## 📦 Установка

```bash
# 1. Клонируйте или распакуйте архив
cd shop_bot_complete

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Создайте .env
mv .env.example .env
# Отредактируйте .env — укажите BOT_TOKEN, LZT_TOKEN, ADMIN_ID

# 4. Запустите
python database.py  # инициализация БД
python bot.py
```

## ⚙️ Переменные окружения

| Переменная | Описание | Пример |
|------------|----------|--------|
| `BOT_TOKEN` | Токен бота | `123456:ABC...` |
| `LZT_TOKEN` | Токен LZT.market | `Bearer ...` |
| `ADMIN_ID` | ID админа | `123456789` |
| `ADMIN_CHAT_ID` | ID группы админов | `-100123...` |
| `REDIS_URL` | URL Redis | `redis://localhost:6379/0` |

## 🎮 Команды админа

| Команда | Описание |
|---------|----------|
| `!статистика` | Статистика магазина |
| `!цена КОД ЦЕНА` | Установить цену |
| `!пользователь ID` | Инфо о пользователе |
| `!тикеты` | Открытые тикеты |
| `!возвраты` | Ожидающие возвраты |

## 🛡 Безопасность

- Автоматическая фильтрация нелегальных источников (брут, фишинг, стиллер)
- Redis-блокировки для предотвращения двойных покупок
- Rate limiting на уровне middleware
- Проверка баланса LZT перед покупками
